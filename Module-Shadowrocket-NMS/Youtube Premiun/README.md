## 🚀 Hướng dẫn sử dụng

1. Tải file `.module` từ thư mục release
2. Mở Shadowrocket > Modules > Import
3. Bật **Script**, **Rewrite**, và thêm các hostname vào MITM
4. Khởi động lại ứng dụng và thưởng thức
